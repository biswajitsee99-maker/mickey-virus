# Mickey Virus public information page

This folder is a static, informational website. It does not contain the local toolkit server or its diagnostic and PC-control features.

## Preview on Windows

Open `index.html` in a browser, or serve this folder with any static-file server.

## Publish safely

Upload only the contents of this folder to a static website host. Do not publish the project root, `website_server.py`, or the local toolkit app. The toolkit backend is designed for loopback use on the owner's computer and must not be exposed to the public internet.

After hosting is configured, add the public domain to Google Search Console and request indexing. Search listing and timing are controlled by Google and are not guaranteed.
